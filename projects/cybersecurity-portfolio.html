A public home for my cybersecurity background, project records and contact details. Its source lets a technical reader inspect how this site is put together; it is not a client security assessment.

Implementation to inspect

Section-based React interface

App.tsx composes separate components for background, experience, projects and contact. Visitors move through a single page using section links.

Static build, responsive styling

The package configuration combines TypeScript checks with a Vite build. The project cards use Tailwind breakpoints to switch from one column to two.

Contact without a site backend

The scoping helper prepares a draft in the browser for the visitor to review, copy or open in their email app. Static HTML retains a direct email route if the application cannot start; the startup boundary hides it only after React commits.

What this work does and does not show

The repository provides inspectable frontend code and an attribution record. It does not establish penetration-testing findings, client outcomes or the security of another system.

A static site also depends on publishing its built assets correctly. An email draft depends on the visitor’s email app or manual copying; it is not a submitted enquiry or confirmed delivery.

Implementation links above point to a fixed source revision so you can check the description. For subsequent changes, review the current repository.
